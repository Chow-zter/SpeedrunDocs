For LiveSplit runners

speedrunDocs

Your route notes next to LiveSplit, in one window. Two documents side by side, and your splits turn the pages for you. Works with manual splits and auto-splitters. No server, no internet needed for the split link.

Windows 10 / 11.NET 8 Desktop RuntimeWebView2 RuntimeLiveSplit component included

Get started

0:00.0
  1. Unzip the download anywhere and double-click speedrunDocs.exe. If Windows asks for the .NET 8 Desktop Runtime or the WebView2 Runtime, install them from microsoft.com.
  2. Open a document on each side: File › Change left document. Paste a Google Docs, Google Sheets or ChatGPT share link and press Enter, or press Import file.
  3. Press Numpad1 or Numpad2 to turn the left or right side to its next page, from any program, even during the game.

Imported files: docx, doc, odt, rtf, pdf, xlsx, ods, txt, md, html, csv, json, epub, or Google's web-page zip. They're kept as read-only copies, so you can delete the download afterwards.

Let your splits turn the pages

2:41

speedrunDocs listens to LiveSplit through a small component. It only writes a local file: nothing goes through a server or the internet. It works the same with manual splits and auto-splitters.

One-time setup, for each layout you use

  1. With LiveSplit closed, copy SpeedrunDocs.dll into LiveSplit's Components folder.
  2. Right-click LiveSplit, choose Edit Layout, press +, then Other, then SpeedrunDocs, then OK.
  3. Right-click LiveSplit and choose Save Layout.

Choose the pages for each split

Open Splits › Edit split pages and type the pages for each side, like 1-3 or 4,5,9. Flip to a page and press Add current to fill it in. An empty box keeps the pages from the split before, so one set can cover several bosses.

Tick Splits › Attach to LiveSplit. Each split now jumps to the first of its pages, and the page keys loop through only that split's pages. Untick it and the keys go through the whole document again.

Page numbers for splits work on imported files and Google Docs. Sheets and ChatGPT pages scroll one screen at a time.

Split notes

20:02

No document? Type or paste notes straight into each split. A side set to split notes shows the current split's notes and changes the moment you split.

  1. Open Splits › Edit split notes and pick the left or right side at the top.
  2. Every split from LiveSplit is listed. Choose one and paste its notes. Alt+↓ moves to the next split, and a dot marks splits that already have notes.
  3. Check the preview: it shows the notes at the size that side has with speedrunDocs maximised, and warns you when they don't fit on one screen.
  4. On the side, open ⋯ › Show split notes here.
You type
# Gryphons
- **Sizz** the left gryphon first
- Whack until both are below half
- Heal Erik at 60 HP, not lower
The side shows
Gryphons
  • Sizz the left gryphon first
  • Whack until both are below half
  • Heal Erik at 60 HP, not lower

Lines stay as typed. **bold**, # headings and - lists also work. Long notes scroll with the page key.

Page keys work from any program, including the game. Num Lock must be on for numpad keys. A key another program already uses shows as taken; pick a different one. If LiveSplit uses the same key, for example Numpad2 for Undo, only one of them gets it.

Profiles

39:25

A profile keeps both documents, their names, which sides are shown, the split pages and the split notes. Switch between them with the Profile box in the top right.

Saved where you chooseOne folder per profile, with copies of any imported files. Set it in File › Profiles folder.
Safe from updatesKeep that folder outside the program's folder. Updating or deleting speedrunDocs never touches it.
Easy to shareCopy a profile folder to another PC and open its profile.json with Ctrl+O.
Undoable deletesDeleting a profile sends its folder to the Recycle Bin.

If something isn't working

1:11:20
Splits don't move the pages
  • Check that Splits › Attach to LiveSplit is ticked.
  • Check that SpeedrunDocs is in the layout you're using, and that you saved the layout.
  • If Edit split pages shows no splits, LiveSplit isn't connected yet.
  • Help › Open error log shows any component errors.
A key shows "taken"
  • Another program already uses that key. Choose a different one in Keybinds › Edit keybinds.
A document side stays blank
  • The side says why it couldn't open the document. Use ⋯ › Reload, or import the file again.
